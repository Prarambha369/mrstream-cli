# MrStream-Cli 📡

> ⚠️ **IMPORTANT**: MrStream-Cli is NOT affiliated with sportsonline.vc, sportssonline.click, or any content provider. Use at your own risk.

MrStream-Cli is a minimalist, terminal-native sports event browser and stream launcher.

## Features
- POSIX-compliant shell scripts (zero-dependency).
- Searchable CLI interface via `fzf`.
- Stream resolution and playback via `mpv`.
- Ethical opt-in source management.

## Installation
```bash
curl -fsSL https://raw.githubusercontent.com/user/mrstream-cli/main/scripts/install.sh | bash
```
